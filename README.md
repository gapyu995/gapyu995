# 🐍 GitHub Contribution Snake

<p align="center">
  <img src="./snake-contribution.svg?v=21-28a5a8b6a094" alt="GitHub contribution snake animation" width="100%" />
</p>

The contribution snake is generated automatically from the GitHub contribution
calendar. The SVG uses SMIL animation and loops seamlessly: every day the
contribution data produces a different set of paths, and the snake follows
several distinct closed routes without any visible reset.
